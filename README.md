# Code-in-Place-Stanford-University-
Fantasy Trader is a hybrid graphical and console-based trading simulation game that challenges players to navigate a volatile virtual financial market. The game features assets like Bitcoin, Ethereum, and Apple stock, each programmed with distinct risk and volatility parameters using the 'random' module.

The project showcases a strong grasp of foundational Python concepts taught in Code in Place, including Object-Oriented Programming (OOP), dictionaries for portfolio and price management, conditional logic for transaction verification, and error handling (try-except) to prevent crashes during user input. 

Key Features:
- Two Game Modes: 10-Day High Score Challenge and Endless Survival Mode.
- Financial Logic: Bankruptcy triggers only if Total Net Worth (Cash + Assets) drops to $0 or below, allowing players to safely go "All-In" on investments.
- Live Graphics: Utilizes the built-in graphics Canvas to dynamically update a beautiful financial dashboard in real-time based on console commands.
